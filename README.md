# ml-neural-network-simulations
This project implements four machine learning simulations using MLP models.
## Problems
1. Multiclass Classification (MNIST)
2. Binary Classification (Breast Cancer Dataset)
3. Regression (California Housing Dataset)
4. Time Series Forecasting (Sine Wave)

## Technologies
- Python
- TensorFlow
- Scikit-learn
- NumPy
- Matplotlib

## Model Structure
All models use:
- tf.keras.Sequential
- One hidden layer (32 neurons)
- Appropriate activation and loss functions.
